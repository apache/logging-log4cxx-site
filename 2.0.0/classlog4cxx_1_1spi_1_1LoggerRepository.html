Detailed Description

A LoggerRepository is used to create and retrieve Loggers.

The relation between loggers in a repository depends on the repository but typically loggers are arranged in a named hierarchy.

In addition to the creational methods, a LoggerRepository can be queried for existing loggers, can act as a point of registry for events related to loggers.

◆ resetConfiguration()

virtual void log4cxx::spi::LoggerRepository::resetConfiguration ( )
pure virtual

Reset all values contained in this repository instance to their default.

This removes all appenders from all categories, sets the level of all non-root categories to null, sets their additivity flag to true and sets the level of the root logger to DEBUG. Also the repository wide threshold is set its default "ALL" value.

Existing categories are not removed.

This method should be used sparingly and with care as it will block all logging until this is configured again.

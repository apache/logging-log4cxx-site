Detailed Description

Sends spi::LoggingEvent elements to a remote a log server, usually in JSON format.

Here is an example configuration that writes JSON to the TCP input plugin of a fluent-bit log server running on the same system as the application:

<log4j:configuration xmlns:log4j="http://jakarta.apache.org/log4j/">
<appender name="A1" class="JSONSocketAppender">
<param name="RemoteHost" value="localhost" />
<param name="Port" value="5170" />
<param name="Threshold" value="INFO" />
</appender>
<root>
<priority value ="INFO" />
<appender-ref ref="A1" />
</root>
</log4j:configuration>

See SocketAppenderSkeleton for more information on the behaviour this appender.

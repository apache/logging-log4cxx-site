Detailed Description

FileAppender appends log events to a file.

Uses a background thread to periodically flush the output buffer when BufferedIO option is set true. Use the BufferedSeconds option to control the frequency, using 0 to disable the background output buffer flush. Refer to FileAppender::setOption() for more information.

Instantiate a FileAppender and open the file designated by filename.

The opened filename will become the output destination for this appender.

If the append parameter is true, the file will be appended to. Otherwise, the file designated by filename will be truncated before being opened.

If the bufferedIO parameter is true, then buffered IO will be used to write to the output file.

◆ setAppend()

void log4cxx::FileAppender::setAppend ( bool newValue)

Set file open mode to newValue.

The Append option takes a boolean value. It is set to true by default. If true, then File will be opened in append mode by setFile (see above). Otherwise, setFile will open File in truncate mode.

Note: The file is opened when activateOptions is called, not when the options are set.

◆ setBufferedIO()

void log4cxx::FileAppender::setBufferedIO ( bool newValue)

Set buffered output behavior to newValue.

By default buffered output is disabled and this appender writes each log message directly to the file. When buffered output is enabled, log messages are stored into a memory buffer and written to the file periodically or when the buffer is full.

Using buffered output will significantly reduce logging overhead.

Note: Behavior change occurs when activateOptions is called, not when the options are set.

Sets and opens the file where the log output will go.

The specified file must be writable.

If there was already an opened file, then the previous file is closed first.

Do not use this method directly. To configure a FileAppender or one of its subclasses, set its properties one by one and then call activateOptions.

The mutex must be locked before calling this function.
